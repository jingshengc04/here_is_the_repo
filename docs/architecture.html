Portfolio Research Agents

You chat with an onboarding agent, and a team of Gemini agents researches the market. They build a two-level portfolio (stocks / crypto / gold → specific tickers), backtest it on real data in Google's code sandbox, and a Verifier rejects it if the risk doesn't match what you asked for.

● Gemini 3.8 Flash ● Gemini 4 Argon ● Deterministic Python (no LLM) ● Inherited from Vibe-Trading ● Frontend (Next.js)

3 · Cross-check

If the sandbox's and our total return and max drawdown differ by more than 0.5 percentage points, the check fails visibly. The UI shows a ✓ Verified badge only when they match.

4 · What "verified" means

These are plain Python rules, not an LLM's opinion. The Argon Verifier only explains failures and suggests fixes.

Drawdown within your risk level

Conservative −20% · Moderate −35% · Aggressive −55%. Measured by the vendored risk x-ray over 5 years.

Sharpe CI lower bound > 0

1,000 bootstrap resamples. Live example: Sharpe 1.01, but 95% CI 0.07–1.89. That honesty about uncertainty is the point.

Sandbox = our numbers

Gemini's sandbox and our pandas must agree within 0.5 percentage points. Live test: 22.12% vs 22.12%.

Sane weights

Weights sum to exactly 100%, no single holding above 25%, and concentration is checked with risk-x-ray HHI.

No look-ahead cheating

We only backtest today's weights over history and say so. We never ask the model what it "would have picked in 2021".

Quant baseline shown

Risk-parity weights sit beside the LLM's allocation, so judges can see where the agents deviate and why.

5 · Inherited from Vibe-Trading vs built new

Vendored (about 2k lines, MIT)

  • backtest/risk_xray.py: drawdown, volatility, VaR, HHI, correlation
  • backtest/validation.py: bootstrap Sharpe CI
  • backtest/optimizers/: risk parity, inverse volatility, mean-variance
  • backtest/loaders/: yfinance, OKX, SEC EDGAR
  • Prompt text from 6 swarm presets and their skill checklists

Built new (ours)

  • FastAPI server, the SSE stream, our API contract
  • 8 single-call Gemini agents (Interactions API)
  • Sandbox backtest + cross-check engine
  • Verifier rules + 2-round rebalance loop
  • Onboarding chat, saved-run replay for the demo

Not inherited (deliberately)

  • Swarm runtime (langchain/langgraph, 30-minute agents): too slow for a live demo
  • Their API server and React UI: the team builds in Next.js against our contract
  • 35+ other loaders. Stooq is blocked by an anti-bot page
