Full flow: how a personal portfolio gets built

From the first chat message to the verified report, using one real run on the current code (live Gemini, Yahoo, OKX and SEC data): $15,000, 6 months, Conservative, with personal preferences. 99 seconds, 9 Gemini calls. Section 7 adds a second real run where round 1 was rejected and fixed.

Gemini 3.8 Flash Gemini 4 Argon Python, deterministic Frontend (Next.js on Vercel)

At a glance

① CHATIntake agent FlashConversation → amount, horizon (≥ 3 months), risk, and any preferences in the user's own words. Ends each reply with a "Saved: …" line.
② CONFIRMConfirm card UIThe user checks or edits everything, then presses Run. Nothing starts automatically.
③ UNDERSTANDPreference resolver FlashMaps any words onto Yahoo's sectors, industries, countries, asset classes and tickers.
④ DISCOVERDiscovery Flash + SearchFinds matching stocks and coins. Adds requested symbols, bonds and defensive ballast, but only if the user's filters allow them.
⑤ RESEARCH ∥Financials · Landscape · News · Social4 agents in parallel: SEC numbers in the sandbox, competitors, news and sentiment. Each holding gets a bull and a bear finding with its own sources.
⑥ ALLOCATEOrchestrator ArgonProposes weights from the findings, the risk-parity baseline and the user's rules. Python normalises and enforces them.
⑦ BACKTEST ×2Sandbox code exec + pandas PythonThe same 5-year backtest computed independently twice. The results must agree within 0.5 percentage points.
⑧ VERIFY9 hard checks Python + Verifier ArgonFail → Argon writes concrete changes → back to ⑥ (max 2 rounds).
⑨ REPORTSummary + notes FlashPie, holdings, evidence, backtest, how each preference was handled, and plain-English reasons if not approved.

  • Captures anything: must-include tickers, exclusions (words or tickers), "only …" universes, asset-class targets (0 = none, e.g. "no gold"), styles, and free-text notes.
  • Horizon: 3 months to 10 years ("3 months" → 0.25).
  • Risk clashes: if a wish clashes with the risk level, it says so once and offers an alternative.
  • Never trades: "buy NVDA now" is politely refused.
  • Truthful confirmation: the green "Saved:" line is generated from the stored data, so the bot can't claim something it didn't save.

③ Preference resolver: the user's words → data filters

One Flash call translates every phrase into Yahoo Finance's taxonomy. Nothing is hard-coded per preference. The same mechanism handles "only biotech", "no gold", "no Chinese companies" or "companies I use every day". The user sees each interpretation in the report:

Interpretation (shown to the user)
'mustInclude: ["DOGE-USD"]' -> insisting on symbol DOGE-USD
'tech companies' -> excluding sector Technology
'oil' -> excluding industries Oil & Gas Drilling, Oil & Gas E&P, Oil & Gas Integrated, Oil & Gas Midstream, Oil & Gas Refining & Marketing, Oil & Gas Equipment & Services
'assetClassTargets: {"CRYPTO": 20.0}' -> targeting 20% in CRYPTO
'I like companies I use every day' -> preferring sectors Consumer Cyclical and Consumer Defensive

Rules: user preferences beat our defaults (gold, bonds, defensive stocks); "must include" beats "exclude"; only risk limits push back, and that's always explained. Everyday words map the way people mean them ("biotech" also covers Yahoo's "Drug Manufacturers", so Amgen and Gilead count; "oil" covers all 6 Oil & Gas industries).

④ Discovery: who gets considered

How candidates are found
  1. Search (Flash + Google, today's date) for names matching the theme, styles and notes.
  2. Add the must-include symbols (DOGE-USD here).
  3. Add bond ETFs by data: lowest 5-year drawdown (2 for Conservative, 1 for Moderate).
  4. Add defensive stocks: lowest 5-year volatility (Conservative/Moderate).
  5. Add gold.
  6. If a restricted universe is thin (< 6 stocks), run one extra search for established names.

⑦ Backtest, computed twice

Gemini's sandbox receives only the weights plus a CSV of 263 weekly prices (2021-10-22 → 2026-10-30) and writes its own Python. Our server computes the same with pandas and Vibe-Trading's risk x-ray. The sandbox never sees our numbers. This run: sandbox 60.2% vs ours 60.3%, a match.

Sharpe 95% confidence interval (1,000 bootstrap resamples): 0.14 to 1.89. The backtest applies today's weights to the last 5 years; it shows how this mix would have behaved, never what it will do.

Loop rules

Honest limits

  • Backtests use the last 5 years for every horizon and apply today's weights; they aren't predictions.
  • Source links are Gemini's redirect URLs (they open the real article), and titles are publisher domains. About 21% of findings fall back to the agent's overall sources.
  • Some News search queries still drift to 2024 dates despite today's date being in the prompt; the findings themselves are dated.
  • Runs are kept in memory on one Cloud Run instance; a restart loses past runs (saved demo replays survive).
